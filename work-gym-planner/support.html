Work + Gym Coach Support

Help with setup, training history, schedules, nutrition, barcode scanning, backups and body statistics.

Run the built-in system check

Open More → System Check. It verifies the main tabs, required interface controls, local storage, encryption support and key coaching functions.

Protect your data first

Before troubleshooting a serious problem, open More → Data & Backup and export a backup if the app is still responsive.

Common fixes

Old version showing: fully close the Home Screen app, reopen while online, or open the latest browser version once.

Camera scanner unavailable: confirm camera permission and try the photo-barcode option or manual barcode entry.

Schedule OCR inaccurate: rotate/crop the photo and review every detected date before saving. Unknown dates remain unknown rather than being treated as days off.

Workout history missing: open Training and use the History button. Only sessions completed with Complete Workout are permanent history entries.

Report a bug

Include the app version, iPhone/iOS version, what you tapped, what happened, and a screenshot if possible. The in-app diagnostics export can help reproduce difficult issues.
